## 🛠️ Admin Panel Mein Aap Kya-Kya Edit Kar Sakte Hain:

### 1. 🎬 Projects Hub (Videos Add, Edit & Delete)
- **Nayi Video Add Karein:**
  - `+ ADD NEW VIDEO PROJECT` button par click karein.
  - Video ka title, client ka naam, duration aur category select karein.
  - **Video Link:** Apna **YouTube video link** (jaise: `https://www.youtube.com/watch?v=...`) ya **Direct MP4 link** paste karein.
  - **Thumbnail Image:** Apni image ka URL paste karein.
  - **Preview Video:** Card hover par video preview ke liye MP4 link paste karein.
  - `SAVE PROJECT` par click karein.
- **Kisi Bhi Project Ko Edit Karein:**
  - Project card ke saamne `EDIT` button dabayein aur koi bhi link ya text update karein.
- **Project Delete Karein:**
  - Red trash icon par click karke kisi bhi project ko remove karein.

### 2. 👤 Profile & Hero Showreel
- Apna Naam, Professional Title, Tagline aur Bio change karein.
- Hero Section mein chalne wali **Main Showreel Video ka Link** aur title badlein.
- Key Milestone Counters (120M+ Views, 240+ Projects, 6+ Years Experience, 99.4% Client Retention) update karein.
- Availability status badlein (jaise: `AVAILABLE FOR SELECT PROJECTS`).

### 3. 🎨 Color Science Comparison
- Interactive split slider ke liye **Raw Flat LOG image** aur **Final Film Grade image** ka link badlein.

### 4. 📱 WhatsApp, Rates & Contact
- **WhatsApp Number:** Apna mobile number country code ke sath daalein (jaise: `+919876543210`). Client ka message direct aapke WhatsApp par aayega!
- **Email:** Apna business email daalein.
- **Social Handles:** Instagram, YouTube, Twitter/X, LinkedIn links update karein.
- **Editing Rates & Turnaround:** Har package ka estimate price aur delivery time badlein.

### 5. 💾 Settings & Permanent Export
- **Change Passcode:** Apna naya password set karein.
- **Download Updated projects-data.js:** 1-click mein updated code file download karein taaki permanent backup rahe.
- **Reset to Demo Data:** Agar kabhi wapas original demo state par jaana ho toh 1-click reset karein.
